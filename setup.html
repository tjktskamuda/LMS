Pasang LMS Sekolah

Tampilan LMS sudah berjalan di GitHub Pages. Halaman ini memandu Anda memasang backend (satu file Code.gs di Google Apps Script) yang menyimpan data di Google Sheets. Waktu yang dibutuhkan ±10 menit, cukup sekali.

DatabaseGoogle Sheets · 14 tab otomatis

  1. Siapkan Google Sheet untuk database

    Buka sheets.new (spreadsheet kosong), beri nama mis. Database LMS. Lalu menu Ekstensi → Apps Script. Kerjakan dari laptop/komputer.

  2. Tempel kode backend

    Lihat kode memuat…

    Di editor Apps Script: klik file Code.gs → Ctrl+A → Ctrl+V → Ctrl+S. Tidak perlu membuat file HTML apa pun.

    Setelah ditempel, gulir ke paling bawah: nomor baris terakhir harus sama dengan jumlah baris di atas.

    Browser tidak mengizinkan salin otomatis. Seluruh kode sudah tersorot di kotak ini — tekan Ctrl+C.

  3. Jalankan setup

    • Di toolbar editor, pilih fungsi setup → klik Jalankan.
    • Muncul permintaan izin: Tinjau izin → pilih akun → Lanjutan → Buka (tidak aman) → Izinkan. Ini wajar untuk skrip buatan sendiri.
    • Semua tab database dibuat otomatis. Opsional: jalankan isiDataContoh untuk mata pelajaran, guru, dan siswa contoh.

  4. Terapkan sebagai aplikasi web

    • Terapkan → Deployment baru → ikon roda gigi → Aplikasi web.
    • Jalankan sebagai: Saya · Yang memiliki akses: Siapa saja → Terapkan.
    • Salin URL aplikasi web (diawali https://script.google.com/, berakhiran /exec).

  5. Hubungkan tampilan ke backend

Memperbarui

    

      
Saat ada Code.gs versi baru
        
Tempel Code.gs baru seperti langkah 2, lalu Terapkan → Kelola deployment → ikon pensil → Versi: Versi baru → Terapkan. URL tetap sama, jadi config.js tidak perlu diubah. Tanpa membuat versi baru, perubahan Code.gs tidak berlaku.

      
Tampilan (frontend)
        
Tampilan diambil langsung dari repo GitHub. Setiap perubahan di repo otomatis tayang dalam ±1 menit; tidak ada yang perlu dilakukan di Apps Script.

    


    
Masalah umum

    

      
“Tidak dapat terhubung ke server”
        
Pastikan akses deployment Siapa saja (bukan “Siapa saja yang memiliki akun Google”) dan URL berakhiran /exec, bukan /dev. Akun Google Workspace sekolah kadang tidak menyediakan pilihan “Siapa saja”; gunakan akun Gmail biasa untuk memasang backend.

      
“Server membalas halaman web, bukan data”
        
URL yang ditempel bukan URL aplikasi web, atau deployment belum diberi izin. Ulangi langkah 3–4 dan salin URL dari jendela deployment.

      
Peringatan “versi server tidak cocok”
        
Code.gs di Apps Script lebih lama dari tampilan. Salin ulang Code.gs dari halaman ini, lalu buat versi deployment baru.

      
Lupa password admin
        
Di Google Sheet, tab Users: hapus baris akun admin. Lalu jalankan fungsi setup — akun admin / admin123 dibuat ulang.

      
Memeriksa backend
        
Jalankan fungsi cekInstalasi di editor Apps Script. Log eksekusi menampilkan status spreadsheet, tab database, akun admin, dan URL aplikasi web.
